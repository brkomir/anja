## Checklist: split-lens gate — evidence and why it is distinct — from `SKILL.md` § Pre-Synthesis Checklist (mandatory — run before writing the synthesis)

  Evidence (2026-04-16): one finding started as single defer "Tier-conditional OG opt-out". Under split-lens: step 2 = "user-controlled toggle design" (genuine — needs data + design), step 3 = "visual rebalance (smaller tier badge, photo-forward composition)" (grounded — existing "tier authoritative not performative" principle, ~30 LOC across 5 OG files). Split into a ship item (visual rebalance) + a revised defer (opt-out toggle). Without the gate, the whole item would have deferred 100%; with the gate, 70% shipped and 30% correctly deferred.

  Why this is distinct from the other two defer gates: default SHIP asks "is this defer valid at all?"; defer without LOC asks "is the effort honest?"; split-lens scope check asks "is the scope correctly decomposed?" — a defer can pass default SHIP + defer without LOC while still having an unrevealed ship-now slice hiding inside. Evidence from the same audit: 73% of defers had ship-now slices discovered only in a later review round. Applying split-lens scope check pre-synthesis would have converted those extra rounds into same-pass splits. Rolling 3-audit defer-promotion rate >30% triggers mandatory split-lens scope check re-audit of all open synthesis defers (as of 2026-04-17, rate is 70%+ across last 3 audits — split-lens scope check applies to next audit from the start).
