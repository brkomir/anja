# /expert-audit — deprecated alias → `/external-audit`

**This command was renamed to `/external-audit` (2026-06-17).** The defining feature is *external-system* calibration; "expert" carried no signal and collided with `/expert-review` (which is also expert-run). "audit" stayed — the posture is gap-finding.

**Execute the `/external-audit` spec** at `.claude/commands/external-audit.md` with whatever subject followed `/expert-audit` — e.g. `/expert-audit claude-system` → run exactly as `/external-audit claude-system`. The full panel, the 3 questions, synthesis rules, and output format all live in that file; do not duplicate them here.

`/expert-audit` continues to resolve here for muscle-memory and for historical references that cite it. New invocations should prefer `/external-audit`. Retire this stub once the old name falls out of use.
